# Dicee-game

A two-player dice game built while learning HTML, CSS, and JavaScript through The App Brewery's Dicee Challenge.

## How to play

1. Download or clone this repository.
2. Open `dicee.html` in your browser, or serve it with VS Code's Live Server extension.
3. Refresh the page to roll both dice again.

Each player receives a random dice roll from 1 to 6, and the page displays a winner message.

## What I practised

- Generating random numbers with `Math.random()` and `Math.floor()`.
- Using `if` and `else` statements.
- Selecting HTML elements and changing image sources with JavaScript.
- Showing hidden headings through the DOM.
- Styling the page with CSS.

## Known limitation

Equal rolls currently display Player 2 as the winner. Handling draws is a future improvement.

## Project files

- `dicee.html` — page structure.
- `styles.css` — page styling.
- `index.js` — dice rolls and winner logic.
- `images/` — six dice images.
